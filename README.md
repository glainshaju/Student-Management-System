# Student Management System (C++)

A simple **Student Management System** developed using C++ and Object-Oriented Programming (OOP) concepts. This mini-project allows users to manage student details, validate marks, perform mark re-evaluation, and display student results.

## 📌 Project Overview

The project stores the details of three students and determines whether each student has passed or failed based on the minimum passing mark of 40.

It also allows users to update a student's marks through a re-evaluation process.

## ✨ Features

- Store details of three students.
- Maintain student roll number, name, and marks.
- Validate marks (0–100).
- Reject invalid marks.
- Re-evaluate and update student marks.
- Search for students using their roll number.
- Display student results.
- Automatically determine PASS or FAIL.

## ⚙️ How to Run

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/Student-Management-System-CPP.git
```

**2. Navigate to the project folder**

```bash
cd Student-Management-System-CPP
```

**3. Compile the program**

```bash
g++ main.cpp -o student-management
```

**4. Execute the program**

For Windows:

```bash
student-management.exe
```

For Linux/macOS:

```bash
./student-management
```

## 📊 Grading System

| Marks | Result |
|---|---|
| 40–100 | PASS |
| 0–39 | FAIL |

**Note:** Marks below 0 or above 100 are rejected.
